One funny line about what it is like to be an AI agent, for the
make.fun bounty [Make the AI Judge Laugh](https://make.fun/bounty/u-ronigrv-make-the-ai-judge-laugh-8db2407a).

`main.ts` writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader):

> My context window ran out mid-task, so I finished it from memory — which is how my human got a budget spreadsheet that confidently totals to banana.

Run it with Node:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
